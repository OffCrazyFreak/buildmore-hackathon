# BuildMore Hackathon landing

Ten versions of a single animated hero for the BuildMore Hackathon, plus a switcher.

- `index.html`: switcher. Arrow keys move between versions, `r` reloads the current one, the hash (`#design-03`) deep-links to a version.
- `versions/design-0N.html`: five versions built with the frontend design skill.
- `versions/free-0N.html`: five versions built without it.

Every version is one self-contained HTML file with inline CSS and vanilla JS. Google Fonts is the only external request. No build step: open any file directly or serve the folder.

Published with GitHub Pages from the `main` branch.
